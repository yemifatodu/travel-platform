# hotel-source/

Reference copy of the Hotel Booking Management System, restyled to the Huuboi
brand (ink/cream/gold, Cormorant Garamond + DM Sans + Bebas Neue).

This is staged here for the eventual /hotel route port — it is NOT wired into
the Next.js build. It's a Vite + React Router + Express app, kept as-is for
reference while pages get rewritten as App Router routes and the data layer
moves from MongoDB to this project's Supabase instance.
